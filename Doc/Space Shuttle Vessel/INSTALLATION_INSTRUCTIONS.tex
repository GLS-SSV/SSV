\section{INSTALLATION INSTRUCTIONS}
\begin{multicols*}{2}

\subsection{Installation}
\noindent
\begin{enumerate}
\item Install Orbiter 2024.

\item Install the required addons:\\
Antelope Valley scenery pack (\url{https://www.orbiter-forum.com/resources/orbiter-2016-high-resolution-texture-packs.5676/})

\item Extract the SSV files into your Orbiter installation folder, overwriting any existing files.\\
\WARNING{The SSV installation overwrites the default Base.cfg and Earth.cfg files.}

\item Install the "SSV\_Font\_A" and "SSV\_Font\_B" fonts, located in the "<Orbiter installation>\textbackslash Install\textbackslash Space Shuttle Vessel" directory, by opening them and selecting "Install". After successful installation the files can be deleted.

\item The displays in SSV require the MFD resolution of 512 x 512 (Orbiter Launchpad $\rightarrow$ Extra $\rightarrow$ Instruments and panels $\rightarrow$ MFD parameter configuration $\rightarrow$ MFD texture size).

\item The local light sources have to be enabled for the external lights in SSV to work (Orbiter Launchpad $\rightarrow$ Visual effects $\rightarrow$ Local light sources, and additionally in D3D9: Orbiter Launchpad $\rightarrow$ Video $\rightarrow$ Advanced $\rightarrow$ Local lights).

\item For a better visual experience, using the D3D9 graphics client is strongly recommended, although not required. If using the D3D9 graphics client, the \textit{Disable near clip plane compatibility mode} option in the D3D9 Advanced Setup dialog (Orbiter Launchpad $\rightarrow$ Video $\rightarrow$ Advanced) should be checked.\\
\end{enumerate}

\NOTE{If you encounter the error "msvcp140.dll is missing" you need to download the Microsoft Visual C++ Redistributable for Visual Studio 2017.}

\subsection{Optional addons}
It is recommended the installation of the excellent Shuttle FDO MFD (\url{https://github.com/indy91/Shuttle-FDO-MFD}) by indy91, which performs the calculations done by the Flight Dynamics Officers in Mission Control, allowing an accurate rendezvous profile simulation, as well as targeting a deorbit burn to land at a chosen runway.\\

\subsection{Known issues}
A compatibility issue has been identified with the addon "Attachment Manager", so it might have to be disabled for SSV to work properly.
\end{multicols*}
